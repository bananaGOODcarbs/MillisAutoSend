# 毫秒定时发送（Android / HarmonyOS 4.3）

这是一个最小 Android Studio 工程。应用本身不联网，不保存输入内容，不设置开机自启。

## 功能

- 输入 `HH:mm:ss.SSS` 格式的目标时间
- 设置提前发送毫秒数
- 通过单调时钟进行最后阶段高精度等待
- 到时优先向当前聚焦输入框执行 IME 发送动作
- 若不支持，自动查找并点击“发送 / Send / 提交”按钮
- 每次只发送一次
- 记录预定派发时间、实际派发时间和计时偏差
- 提供“5 秒后测试发送”

## 构建

1. 使用 Android Studio 打开本文件夹。
2. 等待 Gradle 同步并安装 Android SDK 35。
3. 连接手机，启用 USB 调试，点击 Run；或执行 `Build > Build APK(s)`。
4. APK 通常生成在 `app/build/outputs/apk/debug/app-debug.apk`。

## 手机设置

1. 安装 APK。
2. 打开应用，点击“开启无障碍服务”，启用“毫秒定时发送”。
3. 华为手机进入“设置 > 应用和服务 > 应用启动管理”，关闭自动管理，并允许自启动、关联启动、后台活动。
4. 在“电池优化”中将本应用设为“不允许优化”。
5. 保持屏幕点亮、手机解锁，并停留在目标页面。

## 使用

1. 在目标应用中提前输入文字，让输入框保持焦点。
2. 先用“5 秒后测试发送”验证兼容性。
3. 测试通过后设置目标时间和提前量，点击“开始定时”。
4. 立即切回目标页面，保持页面和输入框状态不变。

## 重要限制

- Android 不是硬实时系统；这里是毫秒级设置、测量和尽力触发，不保证物理点击固定在同一毫秒。
- 一些游戏、Canvas、自绘界面、小程序或受保护页面不会向无障碍服务公开控件。这类页面可能无法使用无坐标方案。
- 如果“5 秒测试”失败，需要针对目标应用的控件结构增加匹配规则，或改用固定坐标手势。
- 请只在你有权操作的账户和页面中使用，并遵守目标应用的使用规则。
